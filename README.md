# 🌱 Brota

**Pequeñas acciones, grandes cambios**

Hola, soy Romina y quiero compartir mi proyecto Brota.

Brota es una aplicación que estoy desarrollando para ayudar a las personas a incorporar pequeñas acciones para cuidar el medioambiente.

La idea es que podamos registrar lo que hacemos cada día, como ahorrar agua, reciclar o ahorrar energía, y ver nuestro progreso en un calendario.

## ☁️ Nubi

Nubi es la mascota de Brota. Quise que la aplicación tuviera un diseño amigable, con colores suaves y que fuera fácil de utilizar.

## 📱 ¿Qué tiene Brota?

- Registro de usuarios e inicio de sesión.
- Calendario para revisar las actividades.
- Tres actividades: ahorrar agua, reciclar y ahorrar energía.
- Resumen de actividades del día, la semana y el mes.
- Diseño pensado para utilizar desde el celular.

## 💻 ¿Qué utilicé?

Para desarrollar Brota estoy trabajando con HTML, CSS, JavaScript, Apache Cordova y Firebase.

También estoy utilizando Git y GitHub para guardar las versiones de mi proyecto.
